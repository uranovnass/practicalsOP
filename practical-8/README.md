# Практическая работа № 8. Взаимоблокировки

## Цель работы

Изучить взаимоблокировки, реализовать алгоритм банкира, поиск циклов в графе ожидания, отслеживание блокировок и исправления задачи обедающих философов.

## Содержание

- `banker.py` — алгоритм банкира: проверка безопасности, обработка запросов и откат.
- `bank1.txt` — безопасное состояние системы.
- `bank2.txt` — небезопасное состояние системы.
- `detector.py` — обнаружение циклов в графе ожидания с помощью DFS.
- `events.txt` — журнал событий захвата, освобождения и ожидания ресурсов.
- `tracked_lock.py` — блокировка с обнаружением цикла ожидания.
- `tracked_lock_test.py` — проверка TrackedLock.
- `deadlock.py` — демонстрация намеренной взаимоблокировки двух потоков.
- `philosophers.py` — два исправления задачи обедающих философов.

## Запуск

```bash
python3 banker.py bank1.txt
python3 banker.py bank2.txt
python3 detector.py events.txt
python3 tracked_lock_test.py
python3 philosophers.py
```

Для демонстрации взаимоблокировки:

```bash
python3 deadlock.py
```

Программа намеренно зависает, поскольку два потока удерживают разные блокировки и ждут блокировки друг друга. Для остановки нажать `Ctrl + C`.

## Вывод

В ходе работы реализованы проверка безопасного состояния алгоритмом банкира, поиск циклов в графе ожидания, отслеживание блокировок и исправления задачи обедающих философов.

## Контрольные вопросы

1. Упорядочивание захвата ресурсов исключает deadlock, потому что не позволяет образоваться циклу ожидания: потоки захватывают ресурсы только в возрастающем порядке.
2. Алгоритм банкира редко применяется в универсальных операционных системах, поскольку требует заранее знать максимальные потребности процессов и иметь информацию о доступных ресурсах.
