# Вариант B — Linux / WSL

## 1. Пользователь student2 и группа developers

### Создание группы

```bash
sudo groupadd developers
```

### Создание пользователя student2

```bash
sudo useradd -m student2
sudo passwd student2
```

### Добавление student2 в группу developers

```bash
sudo usermod -aG developers student2
```

Проверка:

```bash
id student2
```

Пользователь `student2` должен быть участником группы `developers`.

---

## 2. Общий каталог /srv/shared

Создание каталога:

```bash
sudo mkdir -p /srv/shared
```

Владелец и группа:

```bash
sudo chown root:developers /srv/shared
```

Настройка прав:

```bash
sudo chmod 775 /srv/shared
```

Каталог принадлежит пользователю `root` и группе `developers`.

Участники группы `developers` могут создавать и изменять файлы в каталоге, а остальные пользователи не имеют права записи.

Проверка:

```bash
ls -ld /srv/shared
```

---

## 3. Проверка доступа пользователей

Проверка основного пользователя:

```bash
whoami
```

Проверка административных прав:

```bash
sudo whoami
```

Результат:

```text
root
```

Проверка пользователя `student2`:

```bash
su - student2
whoami
```

Результат:

```text
student2
```

Основной пользователь может обращаться к содержимому каталога, но не может удалять или создавать в нём файлы, если не имеет права записи в родительский каталог.

Удаление файла определяется не только правами самого файла, но и правами на каталог, в котором этот файл находится.

---

## 4. sudo и root

В Ubuntu обычная работа выполняется от имени обычного пользователя.

Административные команды выполняются через `sudo`, например:

```bash
sudo whoami
```

Результат:

```text
root
```

Это позволяет выполнять отдельные административные действия без постоянной работы от имени `root`.

## 5. Настройка .bashrc

Файл `.bashrc` используется для настройки окружения пользователя.

Добавлены два alias:

```bash
alias ll='ls -la'
alias c='clear'
```

Также добавлена переменная окружения:

```bash
export STUDENT_NAME="nur"
```

После изменения `.bashrc` настройки применяются командой:

```bash
source ~/.bashrc
```

Проверка alias:

```bash
ll
```

Проверка переменной:

```bash
echo $STUDENT_NAME
```

## 6. Проверка Git

Версия Git:

```bash
git --version
```

Инициализация репозитория:

```bash
git init
```

Добавление файлов:

```bash
git add .
```

Создание коммита:

```bash
git commit -m "Add practical work 1"
```

Проверка состояния:

```bash
git status
```

Если всё сохранено, рабочее дерево должно быть чистым.
