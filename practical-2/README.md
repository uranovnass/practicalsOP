# Практическая работа 2 — Bash, Python и системные вызовы

## Вариант B

В практической работе были изучены обработка лог-файлов с помощью Bash, работа с аргументами командной строки в Python и анализ системных вызовов с помощью `strace`.

---

## 1. Скрипт report.sh

Скрипт `report.sh` анализирует `.log` файлы в указанном каталоге.

### Формат запуска

```bash
./report.sh <каталог> <ERROR|WARN> [--top N]
```

Пример:

```bash
./report.sh data ERROR
```

Скрипт подсчитывает количество сообщений указанного уровня для каждого модуля и выводит результат по убыванию количества сообщений.

### Пример результата

```text
Модуль             Количество
----------------------------
auth               4
api                2
database            2
```

### Фильтрация WARN

```bash
./report.sh data WARN
```

Пример результата:

```text
Модуль             Количество
----------------------------
auth               2
database            2
api                 1
```

---

## 2. Опция --top N

С помощью `--top N` можно вывести только несколько наиболее частых модулей.

Пример:

```bash
./report.sh data ERROR --top 2
```

Вывод содержит два модуля с наибольшим количеством сообщений.

---

## 3. Обработка ошибок

Скрипт проверяет корректность аргументов.

Обрабатываются следующие ошибки:

* отсутствие аргументов;
* неверный уровень `ERROR` или `WARN`;
* несуществующий каталог;
* неправильное использование `--top`;
* значение `N` не является числом.

При ошибке выводится инструкция по использованию:

```text
Usage: ./report.sh <каталог> <ERROR|WARN> [--top N]
```

Скрипт завершает работу с кодом `1`.

---

## 4. Файл hello.py

Файл `hello.py` получает путь к файлу через аргумент командной строки и определяет его размер в байтах.

### Запуск

```bash
python3 hello.py data/01.log
```

Пример результата:

```text
File size: 353 bytes
```

Размер зависит от содержимого файла.

Для чтения файла используется бинарный режим:

```python
open(file_path, "rb")
```

Это позволяет определить точное количество байт.

---

## 5. Анализ системных вызовов

Для анализа работы Python-программы использовалась команда:

```bash
strace -f -o trace.txt python3 hello.py data/01.log
```

Результат сохраняется в файл:

```text
trace.txt
```

Для сравнения использовалась команда:

```bash
strace -f -o trace_cat.txt cat data/01.log
```

Результат сохраняется в:

```text
trace_cat.txt
```

---

## 6. Сравнение Python и cat

При запуске `python3 hello.py` выполняется больше системных вызовов, чем при использовании `cat`.

Это связано с тем, что перед выполнением самого кода Python необходимо запустить интерпретатор, загрузить необходимые библиотеки и подготовить окружение программы.

Команда `cat` является значительно более простой программой, поэтому количество дополнительных системных вызовов меньше.

При этом обе программы используют системные вызовы для работы с самим файлом, например открытия, чтения и закрытия файла.

Таким образом, часть системных вызовов относится непосредственно к чтению файла, а остальные связаны с запуском и работой самой программы.
