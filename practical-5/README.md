# Практическая работа № 5. Симулятор планирования CPU

## Цель работы

Реализовать алгоритмы планирования процессов, рассчитать метрики производительности и сравнить результаты на разных наборах данных.

## Реализованные алгоритмы

- **FCFS** — процессы выполняются в порядке прибытия.
- **SJF** — выбирается процесс с самым коротким временем выполнения.
- **SRTF** — выполняется процесс с наименьшим оставшимся временем.
- **Priority** — вытесняющее планирование по приоритету.
- **RR** — циклическое планирование с настраиваемым квантом времени.
- **Aging** — повышение эффективного приоритета долго ожидающих процессов.

## Структура проекта

- `sched.py` — симулятор CPU.
- `set1.txt` — контрольный набор из четырёх процессов.
- `set2.txt` — нагрузочный набор из двадцати процессов.
- `set3.txt` — короткие процессы и один длинный.
- `starvation.txt` — дополнительный тест старения приоритетов.
- `results/metrics.csv` — результаты запусков.
- `results/rr_quantum.png` — график RR для квантов от 1 до 10.

## Запуск

```bash
python sched.py --algo fcfs set1.txt
python sched.py --algo sjf set1.txt
python sched.py --algo srtf set1.txt
python sched.py --algo priority set1.txt
python sched.py --algo rr --quantum 3 set1.txt
```

Старение приоритетов:

```bash
python sched.py --algo priority --aging --aging-interval 3 set3.txt
```

Построение графика RR:

```bash
python sched.py --plot-rr set2.txt
```

## Метрики

- Среднее время ожидания — сколько времени процессы суммарно ожидали CPU до выполнения.
- Среднее время оборота — время от прибытия процесса до завершения.
- Среднее время отклика — время от прибытия до первого запуска.
- Загрузка CPU — доля времени, в течение которого процессор выполнял работу.
- Число переключений — количество переходов между разными процессами в расписании.

## Вывод

В ходе работы реализованы алгоритмы планирования CPU и вычисление метрик производительности. Сравнение показывает, что выбор алгоритма влияет на ожидание, время отклика и число переключений. Алгоритм RR обеспечивает циклическое распределение CPU, а старение приоритетов уменьшает риск длительного ожидания процессов с низким приоритетом.
