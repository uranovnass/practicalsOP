# Практическая работа № 6. Синхронизация

**Вариант:** B

## Цель работы

Изучить состояние гонки, взаимное исключение, семафоры, условные переменные и барьерную синхронизацию потоков.

## Реализованные программы

- `race.py` — демонстрация состояния гонки при изменении общей переменной несколькими потоками.
- `semaphores.py` — производитель–потребитель с кольцевым буфером на 5 элементов, двумя семафорами и мьютексом.
- `condition.py` — производитель–потребитель с условной переменной, а также демонстрация неправильного использования `if` вместо `while`.
- `barrier.py` — барьерная синхронизация четырёх потоков, выполняющих три фазы.

## Параметры

- Производители: 3.
- Потребители: 2.
- Количество элементов: 1000.
- Размер буфера: 5.
- Количество потоков барьера: 4.
- Количество фаз: 3.

## Проверка корректности

В программах производитель–потребитель проверяются:
- общее количество потреблённых элементов;
- отсутствие пропущенных элементов;
- отсутствие дубликатов;
- отсутствие переполнения и отрицательного счётчика буфера;
- отсутствие оставшихся элементов после завершения.

В программе с барьером все четыре потока должны завершить каждую фазу до перехода за барьер.

## Запуск

```bash
python3 race.py
python3 semaphores.py
python3 condition.py
python3 barrier.py
```

## Вывод

Семафоры ограничивают количество занятых и свободных ячеек, мьютекс защищает критическую секцию, условная переменная позволяет потокам ожидать изменения состояния, а барьер синхронизирует переход между фазами.

Цикл `while` при ожидании необходим для повторной проверки условия после пробуждения потока.
